# История изменений

Формат простой: сверху самые свежие изменения. Даты указывать конкретно,
чтобы потом не вспоминать, когда и что было сделано.

## 2026-07-27

- Добавлена вкладка `События ершей`: отдельная лента для ситуации, когда цена
  ходит туда-сюда внутри узкого диапазона.
- В новой ленте пока используются только `BINANCE` futures и `BYBIT`.
- Добавлены события `ИГОЛКИ` и `СТАКАН`; пробой ерша не ищется.
- Для события `СТАКАН` программа дополнительно проверяет стакан и ищет крупный
  уровень у нижней/верхней границы диапазона.
- Добавлены фильтры событий, очистка ленты, копирование тикера, звук и
  всплывающее окно с отдельными тумблерами.
- Для `Событий ершей` добавлена автоматическая подгрузка истории Binance futures
  и Bybit за 2 часа минутными свечами при старте.
- Вкладка `События ершей` получила строку диагностики: прогрев, кандидаты по
  диапазону, после фильтра иголок и сколько подтвердилось стаканом.
- Обновлены тесты ершей и заметки проекта.

## 2026-07-24

- В `Сканере плотностей` убраны видимые колонки `Best Bid`, `Best Ask` и `Напр.`.
  Направление больше не выбирается вручную: новые и импортированные строки работают в режиме `BOTH`.
- Futures/swap и spot теперь выбираются отдельно в поле `Биржа`: например `BINANCE`
  и `BINANCE SPOT` — разные точные рынки. Пункт `🌐 ВСЕ БИРЖИ` остался для массовой проверки.
- Добавлен ввод тикера без `USDT`: `bank` автоматически становится `BANKUSDT`
  на обычных рынках. Для `BINANCE ALPHA` теперь можно вводить привычные тикеры
  вроде `CAP`; программа сама переводит их в `ALPHA_...USDT`.
- Добавлено автодополнение тикеров под полем `Символ`.
- В `Ленту алертов` добавлены чекбоксы-фильтры по типам событий.
- Крупные долларовые числа в интерфейсе показываются компактно: `$100к`, `$3м`.
- Добавлена кнопка `Тест звука`; проверен fallback звука `ПЛОТНОСТЬ`.
- Добавлены источники стакана `MEXC`, `MEXC SPOT` и `BINANCE ALPHA`.
  Для MEXC futures объём контрактов пересчитывается через `contractSize`.
- Исправлены spec-файлы и `main.py`, чтобы сборка и запуск корректно находили Tcl/Tk runtime.

## 2026-07-23

- Для `BINANCE` и `BINANCE SPOT` добавлена лента raw `trade`: алерты `ПРОЕЛИ`/`СНЯЛИ`/`МАГНИТ`
  получают точную сводку найденных принтов по цене плотности. В `Аудит CSV` добавлены строки
  `TRADE` и trade-сводка в строках `EVENT`; неподтверждённая фраза “сделок по уровню не видно” убрана.
- Нижний блок `Сканера плотностей` стал переключателем: первая вкладка показывает повторяющиеся принты
  (минимум 3, окно времени и похожесть объёма регулируются), вторая вкладка оставляет прежние активные плотности.
- Для `Повторяющихся принтов` добавлен фильтр размера одного принта: `От $` / `До $`.
- Время жизни плотности до минуты теперь показывается с десятыми долями секунды (`10.7с`, а не `0:10`);
  в алерте `ПЛОТНОСТЬ` отдельно виден применённый фильтр `Жизнь, с`, чтобы не путать порог с точным возрастом.
- Добавлен режим `Аудит CSV`: запись событий и активных плотностей в
  `audit_logs\wall_audit_*.csv` для сверки с Tiger/другими терминалами.
- Добавлены удобства в таблицах: правая кнопка копирует тикер с тихим уведомлением,
  `Del`/`Num Del` удаляет все выделенные монеты из сканера, в ленте алертов появилась кнопка очистки.
- Горячие клавиши обрабатываются независимо от раскладки: `Ctrl+C` копирует тикер из активной таблицы
  и работает одинаково на русской/английской раскладке.
- Добавлен экспериментальный `tiger_dom_logger\TigerDomLogger.cs` для записи CSV-снимков стакана Tiger
  через кастомный индикатор Tiger.
- Добавлены spot-рынки для уже подключённых бирж: Binance, AsterDEX, Gate.io,
  OKX.
- На тот момент добавление монеты через базовую биржу проверяло futures/swap + spot;
  с изменениями 2026-07-24 futures и spot выбираются отдельно.
- Spot обозначается в колонке `Биржа`; в ленте алертов символ показывается с
  `SPOT`, но в буфер копируется обычный тикер.
- Добавлено поле `Жизнь, с` для времени подтверждения плотности.
- `Жизнь, с = 0` означает мгновенный алерт без ожидания.
- `Дистанция % = 0` превращается в минимальный практический радиус `0.01%` у
  спреда.
- Добавлен быстрый алерт `ПОД СПРЕДОМ` для плотностей, которые стоят прямо у
  края спреда.
- Комментарии перенесены только в `Ленту алертов`.
- Комментарий редактируется прямо в строке алерта по двойному клику.
- Убрано отдельное окно комментария.
- Нижняя панель статусов бирж сделана компактной.
- Обновлены тесты для zero-фильтров, spot/futures, комментариев и конфигов.
- Добавлены рабочие документы: `WORKFLOW.md`, `RELEASE_CHECKLIST.md`,
  `BUGS.md`.
- Обновлён процесс сборки через `build.bat` / `build_exe.bat`.
