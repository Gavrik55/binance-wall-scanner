# История изменений

Формат простой: сверху самые свежие изменения. Даты указывать конкретно,
чтобы потом не вспоминать, когда и что было сделано.

## 2026-07-23

- Добавлены spot-рынки для уже подключённых бирж: Binance, AsterDEX, Gate.io,
  OKX.
- Добавление монеты через базовую биржу теперь проверяет futures/swap + spot.
- Spot обозначается в колонке `Биржа`; в ленте алертов символ показывается с
  `SPOT`, но в буфер копируется обычный тикер.
- Добавлено поле `Жизнь, с` для времени подтверждения плотности.
- `Жизнь, с = 0` означает мгновенный алерт без ожидания.
- `Дистанция % = 0` превращается в минимальный практический радиус `0.01%` у
  спреда.
- Добавлен быстрый алерт `ПОД СПРЕДОМ` для плотностей, которые стоят прямо у
  края спреда.
- Комментарии перенесены только в `Ленту алертов`.
- Комментарий редактируется прямо в строке алерта по двойному клику.
- Убрано отдельное окно комментария.
- Нижняя панель статусов бирж сделана компактной.
- Обновлены тесты для zero-фильтров, spot/futures, комментариев и конфигов.
- Добавлены рабочие документы: `WORKFLOW.md`, `RELEASE_CHECKLIST.md`,
  `BUGS.md`.
- Обновлён процесс сборки через `build.bat` / `build_exe.bat`.
